# Convite Virtual - App React Native

Aplicativo mobile desenvolvido para a criação de convites digitais interativos. Este projeto renderiza um layout moderno em uma única tela (Single Page Application) e utiliza arquitetura modular dividida em componentes independentes para facilitar a manutenção.

## 🚀 Funcionalidades

* **Cronômetro Dinâmico:** Contagem regressiva em tempo real exibindo dias, horas, minutos e segundos restantes até a data do evento, construída utilizando Hooks (`useState` e `useEffect`).
* **Padrão Regional:** Renderização da data principal do evento formatada rigorosamente no padrão brasileiro (DD/MM/AAAA).
* **Interface Modular:** Sistema arquitetado com a importação de diferentes arquivos (`tela1`, `tela2` e `tela3`) encapsulados dentro do núcleo visual principal para garantir alta performance e fluidez.
* **Design Responsivo:** Layout estruturado com Flexbox, pensado para adaptação automática entre dispositivos iOS e Android.

## 🛠️ Tecnologias e Ferramentas

* React Native
* Expo
* JavaScript (ES6+)

## 📦 Como Executar

Certifique-se de ter o Node.js instalado em sua máquina. Para rodar o projeto localmente:

1. Clone o repositório:
    git clone https://github.com/SEU_USUARIO/convite-virtual-react-native.git

2. Acesse o diretório:
    cd convite-virtual-react-native

3. Instale as dependências:
    npm install

4. Inicie o servidor do Expo:
    npx expo start

*Utilize o aplicativo Expo Go no seu smartphone para visualizar o projeto através do QR Code, ou pressione "a" para abrir no emulador Android e "i" para simulador iOS.*
